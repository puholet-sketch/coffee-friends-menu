# Как собрать меню и залить на флешку

## 1. Заполнить каталог напитков

Файл: `data/drinks.json`

Для каждой позиции:

- `name` — название («Манго чили матча»)
- `volume` — объём («400 мл»)
- `description` — короткая строка («прохладный, острый манго + матча»)
- `image` — путь к фото, например `assets/images/drinks/mango-matcha.jpg`
- `tags` — опционально: `cold`, `signature`, `matcha`

Фото: вертикальные или квадратные, **минимум 800×800 px**, светлый фон, стакан по центру (как Drinkit).

## 2. Положить фото

```
assets/images/drinks/
  mango-matcha.jpg
  latte.jpg
  ...
```

Пока фото нет — в `board.html` показывается цветной placeholder.

## 3. Просмотр в браузере

Откройте `board.html` в Chrome/Edge:

- Слайды листаются автоматически (настраивается в JSON: `settings.slideDurationSec`).
- F11 — полноэкранный режим для записи.

## 4. Записать MP4 для плеера

**Windows (бесплатно):**

1. Открыть `board.html` на весь экран.
2. **Win + G** → Xbox Game Bar → «Запись» на 2–3 цикла меню.
3. Или **OBS Studio** — захват окна, 1080p, 30 fps.
4. Обрезать в **CapCut** / Clipchamp до нужной длины, экспорт **MP4 H.264**.

**Длительность:** 1 слайд ≈ 3.5–5 сек → 10 напитков ≈ 40–55 сек ролика.

## 5. Залить на флешку

1. Флешка **FAT32** (совместимость с плеерами).
2. Один файл в корне: `menu.mp4` (или как требует инструкция плеера).
3. Вставить в плеер → включить питание → проверить loop.

## 6. Обновление меню

Изменили `drinks.json` → пересняли ролик → заменили файл на флешке. Ноутбук в витрине не нужен.
